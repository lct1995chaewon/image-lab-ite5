# 圖像實驗室｜IT-E5 單元三

適合高小學生的繁體中文互動教學網站。不需登入或安裝，不使用 Inkscape。

網站：https://lct1995chaewon.github.io/image-lab-ite5/

## 四個活動
- 3.1 點陣與向量圖同步放大比較。
- 3.2 AI 提示詞配方與規則式教學模擬（不是實際 AI 生成）；真實生成由教師安排。
- 3.3 像素尺寸、色深、原始資料量，以及固定像素下的 PPI 打印尺寸。
- 3.4 JPEG 壓縮與實際檔案大小、JPEG／PNG 下載及 JPEG／PNG／BMP／GIF 格式比較。

## 教師使用
網站上方「教師指引」提供 45–50 分鐘流程、答案、教材對應及可列印學習記錄。

所有活動在瀏覽器本機執行，沒有學生資料上載或 AI API。重新整理後重設活動進度。

## 本機使用與部署
下載儲存庫後，直接開啟 index.html。GitHub Pages 使用 main 分支的根目錄發佈。

依據 ITE5C_u3.pptx 教材重新設計；原教材與教材圖片不包含在此儲存庫。
